# Учёт окупаемости проектов (Payback Tracker)

Минималистичное и быстрое Android-приложение для отслеживания финансовой окупаемости проектов.

## ✨ Возможности

- **Множество проектов**: простое создание, переименование и удаление любых проектов.
- **Только две ключевые операции**:
  - `Потратил` (расход)
  - `Получил` (доход)
- **Фокус на главном**: ввод только суммы, без дат, категорий и лишних комментариев.
- **Наглядный баланс**:
  - Крупные, читаемые цифры баланса.
  - Мгновенная цветовая индикация: зелёный при плюсе (`+`), красный при минусе (`-`).
  - Отображение суммарно потраченного и полученного.
  - История операций проекта с возможностью отмены/удаления ошибочного ввода.
- **100% автономность и приватность**:
  - Локальная база данных **Room (SQLite)** на устройстве.
  - Данные мгновенно сохраняются и сохраняются между перезапусками приложения.
  - Никаких аккаунтов, облаков, интернета или трекеров.
- **Чистый дизайн**:
  - Светлая тема по умолчанию в стиле Material 3.
  - Высокий контраст и отсутствие визуального шума.

---

## 🛠 Технологический стек

- **Язык**: Kotlin
- **UI**: Jetpack Compose (Material 3)
- **Архитектура**: MVVM (Model-View-ViewModel) + UDF (Unidirectional Data Flow)
- **База данных**: Room Persistence Library (SQLite) с поддержкой реактивных потоков `Flow`
- **Асинхронность**: Kotlin Coroutines & StateFlow
- **Навигация**: Jetpack Navigation Compose
- **Сборка**: Gradle 8.11+ (Kotlin DSL), Android Gradle Plugin 8.7+

## 🚀 Как запустить

1. Откройте **Android Studio**.
2. Выберите **File → Open...** и укажите папку `project-payback-tracker`.
3. Дождитесь автоматической синхронизации Gradle.
4. Запустите приложение на эмуляторе или реальном Android-устройстве (кнопка `Run` ▶️).
